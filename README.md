
# Intelligent Last-Mile Delivery Platform

A web-based platform designed to manage delivery orders, drivers, vehicle capacity, traffic conditions, route planning, delivery delays, failed deliveries, customer notifications, and performance analytics.

## Project Goals
- Improve delivery efficiency.
- Optimize delivery routes.
- Track driver and delivery status.
- Reduce failed deliveries.
- Analyze delivery performance.

## Technology Stack
- Frontend: React
- Backend: Node.js and Express
- Database: PostgreSQL
- Version Control: Git and GitHub
- Containerization: Docker and Docker Compose
